Análisis de la capacidad de detección de ataques de red de la matriz MITRE ICS de IDS Opensource y Comerciales


Este repositorio contiene las herramientas y datasets desarrollados para el Análisis de la capacidad de detección de ataques de red de la matriz MITRE ICS de IDS Opensource y Comerciales
.

## 📁 Estructura del Repositorio

El proyecto se organiza de la siguiente manera:

* **`/PCAPS`**: Contiene los archivos de captura de red (`.pcapng`) analizados. 
    * *Nota:* Los archivos de gran tamaño han sido optimizados (muestreados a 100.000 paquetes) para garantizar la portabilidad y eficiencia del análisis sin perder representatividad.
* **`/EXCEL`**: Contiene los reportes generados en formato Excel.
    * Incluye distintas versiones de los resultados del análisis.
    * Contiene el código fuente necesario para la generación automática de estas hojas de cálculo a partir del procesamiento de tráfico.
* **Raíz**: Scripts principales de ejecución del analizador y configuración del entorno.
